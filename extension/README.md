# Active extension source

Install and run checks from the repository root using Bun. Entrypoints live in `entrypoints/`, shared TypeScript in `core/`, retained artwork in `public/`. WXT builds Chrome and Firefox Manifest V3 artifacts into the root `.output/` directory. See the root readme and Documentation/modernization-plan.md. The former Webpack/Jest/yarn workflow is retired; Git history retains it.
